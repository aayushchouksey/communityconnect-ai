# CommunityConnect AI Requirements

CommunityConnect AI is an offline civic assistant helping users access government schemes using voice and text in Hindi and English.

## Features

- Text input
- Voice input
- English to Hindi translation
- Hindi to English translation
- Text summarization
- Offline FAQ support
- Personalization (Student, Farmer, Job Seeker)
- Voice output

## Users

- Students
- Farmers
- Job seekers

## Goal

Make government schemes accessible easily.
